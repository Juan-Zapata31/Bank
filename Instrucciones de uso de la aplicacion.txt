Flujo para crear transferencias.

Primer paso: Iniciar sesión con el usuario analista, que es analyst01 y la clave es admin123

Segundo paso: Se crea el empleado de la empresa que es companyemp04 y la clave admin123

Tercer paso: Se inicia sesión con el usuario comercial que es comercial01 y la clave admin123

Cuarto paso: Se crea el cliente natural con los siguientes datos: 


{
  "fullName": "Pedro Pérez",
  "documentNumber": "1100000006",
  "email": "pperez@mail.com",
  "phone": "3101111006",
  "address": "Calle 90 # 20-40",
  "birthDate": "1988-03-12"
}


Quinto paso: Se inicia sesión con el cajero que es teller01 y la clave admin123

Sexto paso: Se crea la cuenta empresa el cual el cliente es el número 6 (Recordar anotar el id que me devolvió)

con la siguiente información: 

{
  "accountType": "BUSINESS",
  "clientId": 6,
  "currency": "COP"
}

Séptimo paso: Se crea la cuenta natural para el cliente que ya está creado, el cual es el número 7 con los siguientes datos:
Anotar también el id que me devuelve
{
  "accountType": "SAVINGS",
  "clientId": 7,
  "currency": "COP"
}

Octavo paso: Se realiza un deposito con el id de la cuenta que creó y el monto, pero antes de hacer la transferencia, debo iniciar sesión con el cajero

{
  "accountNumber": 5,
  "amount": 5000000
}


Noveno paso: Se realiza inicio de sesión con el empleado empresa con el usuario companyemp04 y la clave admin123

Décimo paso: Crear la transferencia con el id que me devolvió la creación de la cuenta cliente natural con los siguientes datos:

{
  "originAccount": 5,
  "destinationAccount": 6,
  "amount": 2000000,
  "currency": "COP",
  "description": "Pago de servicios febrero"
}

El estado de la transferencia debería quedar en pendiente ya que esta necesita aprobación

Onceavo paso: Se realiza inicio de sesión con el empleado supervisor con el usuario companysup02 y la clave admin123

Doceavo paso: Se realiza la aprobación de la transferencia con el id devuelto cuando se creó la transferencia
